# Chart of Accounts Practice Tool
### ACCT 2301 — Financial Accounting

[![DOI](https://zenodo.org/badge/1219995133.svg)](https://doi.org/10.5281/zenodo.19989532)

An interactive, browser-based practice tool for introductory financial
accounting students. Students practice identifying accounts, the categories
they belong to, and the financial statements they appear on — based on the
Chapter 1 Framework for Financial Accounting.

## Learning Objectives

Students who use this tool will be able to:

- Identify common accounts and classify them by account type
- Match accounts to the correct financial statement
- Recognize common tricky accounts such as Deferred Revenue and
  Dividends Payable as liabilities
- Self-assess understanding and focus study efforts on missed questions

## How to Access

**[Open the practice tool here](https://jenncoon.github.io/COA/)**

No installation required. Runs in any desktop or tablet browser.

## How It Works

- Students select a section mode aligned to their place in the course:
  Section 1 covers accounts introduced before Exam 1, with Sections 2
  and 3 introducing new accounts for their respective exam windows
- Students read an account or category prompt and select the correct answer
- Instant feedback is provided after each question with a brief explanation
- A missed question summary at the end helps students focus their review
- Each attempt draws a fresh random set of questions for repeated practice
- A Quick Reference card is available on the home screen for review
  before starting

## Instructor Notes

- Designed for use in Financial Accounting (ACCT 2301) or equivalent
  introductory course
- Sections align to a three-exam course structure; instructors using a
  different structure may want to direct students to specific sections
- No login or LMS integration required; students access directly via link
- Works well as a low-stakes study tool before exams or as a course
  orientation activity in the first week
